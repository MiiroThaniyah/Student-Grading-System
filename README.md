# Student-Grading-System
# BBC2 Grading System
This is our java student grading system that combines loops(while, do-while, for) and ternary  statement into one working project
# How it works
When you run the program, it asks you for the admin password before letting you in. You only get three attempts if you get it correct, you are logged in and if you get it wrong three times , the program locks you out and closes.
When you are logged in, you can enter student records one at a time;
student name and student score (0-100)
The program uses a ternary operator( score<50 ? "FAIL": "PASS")
The program grades  using if else if conditions:
90 and above - A
80-89  B
70-79  C
60-69  D
50-59  E
Below  50 F
After  entering the student, your asked if you want to enter another student you can enter ('y' /'Y')  to continue.
This repeats using a do-while loop
The for loop lastly prints you a reference table showing the grading scale so that someone using the program can know the grading scale

while loop- Login attempts
do-while loop - Repeatedly entering student records
for- loop- Printing  the grading scale reference table
Ternary operator -  for the pass/fail check
